# KNN Analysis - Breast Cancer Classification

A comprehensive K-Nearest Neighbors analysis for breast cancer classification using scikit-learn.

## Features
- Automated hyperparameter tuning
- Cross-validation for robust evaluation
- Multiple evaluation metrics (Accuracy, AUC, Confusion Matrix)
- Professional visualizations
- Clean, documented code structure

## Results
- Achieved 96%+ accuracy on breast cancer dataset
- Optimal K value determined through cross-validation
- ROC-AUC score: 0.98+

## Technologies Used
- Python, scikit-learn, pandas, matplotlib, seaborn
