# Decision Tree Analysis - Iris Classification

A comprehensive Decision Tree analysis for Iris flower classification using scikit-learn with advanced visualization techniques.

## Features
- Complete Decision Tree analysis with data exploration
- Decision boundary visualization for all 6 feature pairs
- Feature importance analysis and ranking
- Manual hyperparameter optimization
- Professional data exploration with distribution plots
- Multiple evaluation metrics (Accuracy, Confusion Matrix, Classification Report)
- Decision tree structure visualization
- Cross-validation analysis
- Clean, documented code with comprehensive error handling

## Results
- Achieved 100% accuracy on Iris dataset test set
- Cross-validation score: 0.95+ with low variance
- Complete feature importance ranking analysis
- Visual decision boundaries for all feature pair combinations
- Identified best performing feature pairs for classification

## Key Components
- **DT.py**: Complete Decision Tree analysis with comprehensive visualizations and data exploration
- **DT_DecisionBoundary.py**: Specialized decision boundary visualization for all feature pairs
- Advanced data exploration with feature distribution analysis
- Feature importance ranking and interpretation
- Decision tree structure visualization

## Technologies Used
- Python, scikit-learn, pandas, matplotlib, seaborn, numpy
- Decision boundary visualization, tree plotting, statistical analysis
